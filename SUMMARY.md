## 🚀 How to Use (3 Simple Options)

### Option 1: Super Quick Start (Easiest!)

```bash
# Extract the zip
unzip AIhubBackend.zip
cd AIhubBackend

# Run this ONE command
python quick_start.py
```

**That's it!** The script will:
- ✅ Check dependencies
- ✅ Install what's needed
- ✅ Generate an API key (jpnohub-xxxxx)
- ✅ Save it to .env
- ✅ Start the backend server

Server runs on: `http://localhost:8000`
API Docs: `http://localhost:8000/docs`

### Option 2: Interactive Testing

```bash
python backend_tester.py
```

**Interactive menu with:**
1. Generate and test API keys
2. Check dependencies
3. Test backend imports
4. Start backend server
5. Do all checks and start server
6. Exit

### Option 3: Test the API

Once server is running (open NEW terminal):

```bash
python api_client.py
```

**Test endpoints like:**
- `/health` - Server status
- `/providers` - List AI providers
- `/api/generate-key` - Create new keys
- `/chat` - Send messages to AI
- `/models` - List available models
- `/conversations` - View history

## ⚙️ Configuration

Edit `backend/.env` to add your AI provider keys:

```env
# Get these from provider websites
GEMINI_API_KEY=your-key-here
OPENAI_API_KEY=your-key-here
ANTHROPIC_API_KEY=your-key-here

# Auto-generated by quick_start.py
BOT_API_KEY=jpnohub-automatically-generated
```
