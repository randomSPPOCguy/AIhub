# AI Hub Backend - Terminal Only Setup

## 🚀 Super Quick Start (Recommended)

Just run this one command:

```bash
python quick_start.py
```

That's it! This will:
- ✅ Check your Python version
- ✅ Install all dependencies
- ✅ Generate an API key automatically
- ✅ Start the backend server
- ✅ Show you the API documentation URL

## 📋 What You Get

This is your AI Hub backend **without** the Electron/UI complexity:

- ✅ **FastAPI Backend** - Clean REST API
- ✅ **Multiple AI Providers** - Gemini, OpenAI, Claude
- ✅ **API Key System** - Generate keys with `jpnohub-` prefix
- ✅ **Terminal Testing Tools** - Easy to test everything
- ✅ **No UI Bloat** - Just the backend, nothing else

## 🎯 Three Ways to Use This

### Option 1: Super Quick (Easiest)

```bash
python quick_start.py
```

Done! Server running on http://localhost:8000

### Option 2: Interactive Testing

```bash
python backend_tester.py
```

Choose from menu:
1. Generate API keys
2. Check dependencies
3. Test imports
4. Start server
5. Do everything automatically

### Option 3: Manual Control

```bash
# Install dependencies
cd backend
pip install -r requirements.txt --break-system-packages

# Generate API key
python generate_api_key.py

# Start server
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## ⚙️ Configuration

### Add Your AI Provider Keys

Edit `backend/.env`:

```env
# Your AI Provider API Keys
GEMINI_API_KEY=your-gemini-api-key-here
OPENAI_API_KEY=your-openai-api-key-here
ANTHROPIC_API_KEY=your-anthropic-api-key-here

# Hub API Key (auto-generated by quick_start.py)
BOT_API_KEY=jpnohub-automatically-generated

# Optional Settings
LOG_LEVEL=INFO
CORS_ORIGINS=*
```

### Get API Keys From:

- **Gemini**: https://makersuite.google.com/app/apikey
- **OpenAI**: https://platform.openai.com/api-keys
- **Claude**: https://console.anthropic.com/

## 💡 Common Tasks

### Use Local AI Models (No API Keys!)

**RECOMMENDED: Use ONNX Runtime (Much Faster!)**

With your **RTX 4060**, ONNX is 10-25x faster than PyTorch:

```bash
# Install ONNX Runtime with DirectML (Windows GPU)
cd backend
pip install onnxruntime-directml --break-system-packages

# Test your setup
python test_onnx.py

# Start the backend
python -m uvicorn main:app --reload
```

**Alternative: PyTorch (slower but more models)**

```bash
# Install PyTorch
cd backend
pip install transformers torch accelerate --break-system-packages

# Test local models
python test_local_models.py
```

**Supported models:**
- microsoft/Phi-3-mini-4k-instruct (default)
- Qwen/Qwen2.5-3B-Instruct
- Any HuggingFace model!

See `ONNX_GUIDE.md` (recommended) or `LOCAL_MODELS.md` for full guides.

## 🔧 Troubleshooting

### "Module not found" errors

```bash
cd backend
pip install -r requirements.txt --break-system-packages
```

### Port 8000 already in use

```bash
# Find what's using it
lsof -i :8000

# Or use a different port
python -m uvicorn main:app --port 8001 --reload
```

### ONNX/GPU warnings

These are optional features. You can ignore warnings about:
- onnxruntime-genai-cuda
- CUDA
- GPU acceleration

The backend works fine without them!

### Dependencies fail to install

Some packages (like ONNX) may fail on certain systems. That's okay!
The core functionality will still work. Just proceed anyway.
