# AI Models Index

This directory contains the AI models used by AIhub.

## Directory Structure

- `downloads/` - Active models downloaded and ready for use
- `backups/` - Backup copies of models for recovery purposes

## Active Models

| Model | Location | Description |
|-------|----------|-------------|
| phi-3-mini-onnx-cuda | downloads/phi-3-mini-onnx-cuda | Microsoft Phi-3 Mini ONNX model with CUDA support |

## Usage

The models in the `downloads` directory are used by the Python ONNX server for AI inference.
Start the ONNX server using the `/py` command in the AIhub console.
